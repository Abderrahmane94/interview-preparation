# Nouveautés en 8, 11 & 17
# <TOCInline toc={toc} />

## Quelles sont les nouveautés de Java 8 ?

1. **Expressions Lambda** : permettent de représenter des fonctions anonymes et d'activer la programmation fonctionnelle en Java. Syntaxe concise pour écrire des fonctions inline, améliorant la lisibilité et permettant l'utilisation des interfaces fonctionnelles.

2. **Stream API** : fournit une façon fluide et fonctionnelle de traiter des collections de données. Les streams permettent un traitement séquentiel ou parallèle efficace avec des opérations comme map, filter, reduce et plus encore.

3. **Méthodes par défaut** : permettent d'ajouter des méthodes aux interfaces sans rompre les implémentations existantes. Maintiennent la compatibilité ascendante.

4. **Optional** : conteneur pouvant contenir ou non une valeur non-null. Encourage une meilleure gestion des valeurs null et aide à éviter les `NullPointerException`.

5. **API Date et Heure** : nouvelle API dans le package `java.time`. Meilleure immuabilité, sécurité des threads, et support des fuseaux horaires par rapport aux anciennes `java.util.Date` et `java.util.Calendar`.

6. **Références de méthode** : syntaxe abrégée pour référencer des méthodes ou constructeurs. Simplifient le code lors du passage de méthodes en arguments.

7. **Interfaces fonctionnelles intégrées** : le package `java.util.function` introduit `Predicate`, `Function`, `Consumer`, `Supplier`. Facilitent l'utilisation des lambdas et représentent des patterns fonctionnels courants.

8. **CompletableFuture** : framework puissant pour la programmation asynchrone. Supporte la composition, combinaison et chaînage de tâches asynchrones pour écrire du code non-bloquant et réactif.

## Quelles sont les nouveautés de Java 11 ?

1. **Syntaxe var pour les paramètres lambda** : Java 11 étend le mot-clé `var` pour l'utiliser comme paramètre dans les expressions lambda, permettant l'inférence de type.

2. **API HTTP Client (standard)** : nouvelle API HTTP intégrée dans `java.net.http`. Plus moderne et efficace, remplace l'ancienne `HttpURLConnection`.

3. **Epsilon** : nouveau garbage collector expérimental n'effectuant aucune gestion mémoire (no-op). Utile pour les tests de performance ou les applications très éphémères.

4. **Exécution de fichiers source mono-fichier** : possibilité d'exécuter directement des fichiers source Java avec la commande `java`, sans compilation explicite. Simplifie l'exécution de petits programmes.

5. **ZGC (expérimental)** : garbage collector scalable à faible latence. Vise des pauses constantes quelle que soit la taille du tas, adapté aux grandes applications haute performance.

6. **Flight Recorder** : outil de profilage et de diagnostic (anciennement commercial) rendu disponible dans OpenJDK. Collecte des informations de bas niveau sur l'application Java pour l'analyse de performance.

7. **Support Unicode 10** : jeux de caractères, scripts et propriétés définis dans Unicode 10.0.0.

8. **Dépréciation des modules Java EE et Corba** : supprimés du classpath par défaut. Ces technologies font désormais partie de la plateforme Jakarta EE.

9. **Suppression de JavaFX** : retiré de Java SE depuis Java 11, maintenant développé séparément en dehors du JDK.

Java 11 est une version LTS (Long-Term Support), ce qui signifie qu'elle bénéficiera de mises à jour et d'un support pendant une période prolongée.

## Quelles sont les nouveautés de Java 17 ?

Java 17 est une version LTS avec plusieurs ajouts importants :

1. **Classes scellées (Sealed Classes)** : restreignent quelles classes peuvent étendre ou implémenter une classe/interface. Donne le contrôle sur les hiérarchies d'héritage.

```java
public sealed class Forme permits Cercle, Rectangle, Triangle {}
public final class Cercle extends Forme { double rayon; }
public final class Rectangle extends Forme { double largeur, hauteur; }
```

2. **Pattern matching pour `instanceof`** (finalisé) : élimine le besoin de cast explicite après une vérification `instanceof`.

```java
// Ancien
if (obj instanceof String) { String s = (String) obj; System.out.println(s.length()); }

// Java 17
if (obj instanceof String s) { System.out.println(s.length()); }
```

3. **Expressions switch** (finalisées depuis Java 14) : le switch peut maintenant retourner une valeur avec la syntaxe `->`.

```java
String resultat = switch (jour) {
    case LUNDI, VENDREDI -> "Chargé";
    case SAMEDI, DIMANCHE -> "Libre";
    default -> "Normal";
};
```

4. **Blocs de texte (Text Blocks)** (finalisés depuis Java 15) : chaînes multi-lignes sans séquences d'échappement.

```java
String json = """
    {
        "nom": "Alice",
        "age": 30
    }
    """;
```

5. **Records** (finalisés depuis Java 16) : classes porteuses de données immuables et compactes. Génèrent automatiquement `equals()`, `hashCode()`, `toString()` et les accesseurs.

```java
public record Point(int x, int y) {}

Point p = new Point(1, 2);
p.x();         // 1
p.toString();  // Point[x=1, y=2]
```

6. **Messages NullPointerException améliorés** : messages plus utiles indiquant précisément quelle variable était null.

```java
// Avant : NullPointerException
// Après : Cannot invoke "String.length()" because "str" is null
String str = null;
str.length();
```

7. **Suppression de l'API RMI Activation et Applet** : technologies héritées supprimées.

8. **API RandomGenerator améliorée** : nouvelles interfaces pour la génération de nombres aléatoires avec meilleure prévisibilité et pluggabilité.

```java
RandomGenerator rng = RandomGeneratorFactory.of("Xoshiro256PlusPlus").create();
int n = rng.nextInt(100);
```

## Quelles sont les nouveautés de Java 21 ?

Java 21 est la prochaine version LTS après Java 17, avec des améliorations majeures du langage et du runtime :

1. **Threads Virtuels** (Project Loom) : threads légers gérés par la JVM, pas l'OS. Permet une haute concurrence sans code asynchrone complexe.

```java
// Créer un thread virtuel
Thread vThread = Thread.ofVirtual().start(() -> System.out.println("Virtuel !"));

// Utiliser avec ExecutorService (meilleur pattern)
try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {
    executor.submit(() -> traiterRequete()); // chaque tâche obtient son propre thread virtuel
}
```

Les threads virtuels sont peu coûteux à créer (des millions possibles), bloquent sans mobiliser de threads OS, et font évoluer le code bloquant comme du code asynchrone.

2. **Pattern matching pour switch** (finalisé) : combiner `switch` avec des patterns de type et des patterns gardés.

```java
static String decrire(Object obj) {
    return switch (obj) {
        case Integer i when i < 0 -> "Entier négatif : " + i;
        case Integer i -> "Entier positif : " + i;
        case String s -> "Chaîne de longueur " + s.length();
        case null -> "null";
        default -> "Autre : " + obj;
    };
}
```

3. **Collections séquencées (Sequenced Collections)** : nouvelles interfaces `SequencedCollection`, `SequencedSet`, `SequencedMap` avec accès cohérent au premier/dernier élément.

```java
List<String> liste = new ArrayList<>(List.of("a", "b", "c"));
liste.getFirst(); // "a"
liste.getLast();  // "c"
liste.reversed(); // vue : ["c", "b", "a"]
```

4. **Patterns de record (Record Patterns)** : déconstruire les valeurs de record dans les patterns.

```java
record Point(int x, int y) {}

if (obj instanceof Point(int x, int y)) {
    System.out.println(x + ", " + y); // x et y sont directement liés
}
```

5. **Templates de chaînes (Preview)** : intégrer des expressions directement dans les chaînes (similaire aux template literals JS).

```java
String nom = "Alice";
String salutation = STR."Bonjour, \{nom} !"; // "Bonjour, Alice !"
```

6. **Concurrence structurée (Preview)** : traiter un groupe de tâches liées comme une unité, simplifiant la gestion des erreurs et l'annulation.

```java
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    Future<String> utilisateur = scope.fork(() -> recupererUtilisateur(id));
    Future<Commande> commande = scope.fork(() -> recupererCommande(id));
    scope.join().throwIfFailed();
    return new Reponse(utilisateur.resultNow(), commande.resultNow());
}
```
